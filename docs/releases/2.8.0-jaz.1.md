# Codex ACP 2.8.0-jaz.1

Upstream Codex ACP 2.8.0 with native Codex 0.170.0 and ACP SDK 2.8.

Changes to the fork:

- A subagent's turn start no longer replaces the session's turn id. In 2.6.0-jaz.1 every steer after a subagent started was sent with the subagent's turn id, and Codex rejected it.
- The `_session/mcp/refresh` extension is removed. Codex 0.170.0 keeps a loaded thread's tool catalog through `config/mcpServer/reload` and `notifications/tools/list_changed`; the client resumes the thread in a new process instead.
- The session's `threadHasHistory` flag is restored, which the retained prompt ID lookup of 2.8.0 reads.

Validation on macOS arm64:

- Standard suite: 2,536 passed, 38 existing skips.
- Integration suite against the native runtime with a local model-provider stand-in: 23 passed, without real authentication.
- TypeScript and examples typecheck; the compiled adapter answers `initialize` and advertises steering with completion.
- The extracted archive reports adapter 2.8.0-jaz.1 and native Codex 0.170.0.

Authenticated parity checks were not run locally.
